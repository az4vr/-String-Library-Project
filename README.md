# String-Library-Project
The String Library Project is a collection of useful functions designed to simplify string manipulation and provide an easy way to work with text.

# clsString – String Library Functions

- CountWords() – Counts the number of words in a string
- Length() – Returns the length of the string.
- UpperFirstLetterOfEachWord() – Converts the first letter of each word to uppercase.
- LowerFirstLetterOfEachWord() – Converts the first letter of each word to lowercase
- UpperAllString() – Converts all letters to uppercase.
- LowerAllString() – Converts all letters to lowercase.
- InvertLetterCase() – Inverts the case of a single character.
- InvertAllLettersCase() – Inverts the case of all letters in a string.
- CountLetters() – Counts letters based on a specified type.
- CountCapitalLetters() – Counts uppercase letters.
- CountSmallLetters() – Counts lowercase letters.
- CountVowels() – Counts the vowels in a string.
- CountSpecificLetter() – Counts occurrences of a specific character.
- IsVowel() – Checks whether a character is a vowel.
- Split() – Splits a string into a vector of words or tokens.
- TrimLeft() – Removes spaces from the beginning of a string.
- TrimRight() – Removes spaces from the end of a string.
- Trim() – Removes spaces from both ends of a string.
- JoinString() – Joins elements of a vector or array into one string.
- ReverseWordsInString() – Reverses the order of words in a string.
- ReplaceWord() – Replaces a specific word with another word.
- RemovePunctuations() – Removes punctuation marks from a string.
